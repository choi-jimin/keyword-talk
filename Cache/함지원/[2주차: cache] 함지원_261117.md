## 용어 정리
### Hash Tag
`user:1001:name "박XX"`라는 데이터가 있다고 가정했을때, `key`값에 `{}`를 씌우는 방법이다.(`user:{1001}:name "박XX"`)

> **그럼 해시태그의 장점은 뭘까?**
> 같은 해시 태그안에 `key`값들을 같은 SLOT에 모을 수 있다는 것이다.

### SLOT
SLOT이란 Redis Cluster에서 `key`를 분류하고, 각 키를 어느 노드가 담당할지 결정하기 위한 논리적인 분할 단위이다.(16,384개 존재)

### MGET<sup>MultiGET
여러 키의 값을 한 번에 조회하는 Redis 명령어이다.

```text
user:{1001}:name    "홍길동"
user:{1001}:email   "hong@example.com"
```
**`GET`**
```redis
GET user:{1001}:name
# "홍길동"
```

**`MGET`**
```redis
MGET user:{1001}:name user:{1001}:email
# 1) "홍길동"
# 2) "hong@example.com"
```

## 가져올 데이터가 많다면?
>- 해시 태그로 SLOT 분배, MGET 요청 최적화

해시 태그로 SLOT 분배를 했을 때, SLOT 안에 해시 태그로 감싸져 있는 `key`값들이 서버 안에 담기기 때문에 한 번의 `MGET` 명령으로 묶을 수 있다.

1. 같은 해시태그로 데이터 저장
```redis
SET user:{1001}:name "홍길동"
SET user:{1001}:email "hong@example.com"
```
**SLOT**
```text
슬롯 15391
├─ user:{1001}:name  → "홍길동"
└─ user:{1001}:email → "hong@example.com"
```
2. `key`들을 지정해서 `MGET` 실행
```redis
MGET user:{1001}:name user:{1001}:email
```

**결과**
```text
1) "홍길동"
2) "hong@example.com"
```

## 원자적 처리가 가능하다면?
>- lua script 활용

### Lua Script란?
Lua 프로그래밍 언어로 작성되어 Lua 실행 엔진이 해석하고 실행하는 프로그램 코드이다.

여러 Redis 작업 사이에 다른 요청이 끼어들면 안 될 때, 그 작업들을 Lua Script 하나로 묶어서 실행한다.

```text
구매자 A: [재고 조회 → 확인 → 차감]
구매자 B:                          [재고 조회 → 확인 → 차감]
```
