## 🕐 진행 방식

- **언제**: 매주 목요일 22:00 (약 1시간)
- **어디서**: 온라인 (디스코드)

### 1. 스터디 전

1. 지난 스터디에서 정한 **내 키워드**를 공부해요.
2. `weekNN/이름-키워드.md` 파일에 [템플릿](./TEMPLATE.md)대로 짧게 메모해요.
3. 스터디 전날까지 PR로 올려요. (리뷰 승인 없이 바로 머지해도 OK)
4. 토크를 시작할 **질문 하나**를 준비해 와요.
   > 예: "DB에 요청할 때마다 연결을 새로 맺으면 무슨 일이 생길까?"

### 2. 스터디 시간

| 시간 | 내용 |
| --- | --- |
| 5분 | 근황 토크, 지난주 남은 질문 답 공유 |
| 40분 | 키워드 토크 (한 사람당 약 10~12분) |
| 10분 | 🅿️ 주차장 시간: 미뤄둔 얘기 + 오늘 키워드들 연결해보기 |
| 5분 | 다음 주 키워드 고르기, 다음 진행자 정하기 |

#### 키워드 토크는 이렇게

1. **질문으로 시작** (1분): 준비한 질문을 던지고 다 같이 잠깐 생각해봐요.
2. **짧게 설명** (3분 내외): 내가 이해한 만큼만 설명해요. 그림을 그리면 더 좋아요.
3. **길게 대화** (나머지): 듣는 사람들이 질문하고 덧붙여요.
4. **모르는 것으로 마무리**: "여기까지 이해했는데, 이 부분은 모르겠어"로 끝내도 좋아요.

#### 막힐 때 꺼내 쓰는 질문

- 그게 없으면 어떻게 돼?
- 실제로 어디서 쓰여?
- 비슷한 거랑 뭐가 달라?
- 그럼 단점은 뭐야?
- 아까 그 키워드랑은 어떤 관계야?

### 3. 스터디 후

- **회고**: 진행자가 녹음을 바탕으로 `weekNN/회고.md`를 정리해요. (아래 **녹음과 AI 정리** 참고)
- **남은 질문**: 이슈로 등록하고 담당자를 지정해요. 다음 주 시작할 때 답을 공유해요.
- **내 메모 고치기**: 토크하면서 잘못 이해한 부분을 알게 됐다면 그 주 안에 고쳐요.
- **한 달에 한 번**: 지금까지 다룬 키워드를 하나의 흐름으로 엮어보는 문서를 같이 만들어요.
  > 예: "사용자가 주문 버튼을 눌렀을 때 서버에서 일어나는 일"

## ⏱️ 대화가 길어질 때

- **진행자가 시간을 지켜요.** 매주 돌아가며 맡고, 남은 시간 1~2분에 알려줘요.
- **🅿️ 주차장에 두기**: 옆길로 새거나 깊어지는 얘기는 메모해두고 주차장 시간에 이어가요.
- **그래도 남으면 넘기기**
  - 한 키워드를 더 깊게 파고 싶다 → 다음 주에 **심화편**으로 이어가기
  - 다른 키워드로 번졌다 → **새 키워드로 이슈 등록**
- **시간이 계속 부족하면**: 한 주에 모두 하지 않고 2명씩 나눠서 진행해요.
- **대화가 정말 잘 붙는 날은**: 모두 동의하면 남은 키워드를 다음 주로 미루고 끝까지 얘기해도 괜찮아요.

## 🎙️ 녹음과 AI 정리

스터디는 디스코드에서 진행하고, [Craig](https://craig.chat) 봇으로 녹음해요.
대화에만 집중하고, 정리는 녹음과 AI의 도움을 받아요.

### 녹음하기

1. 스터디 서버의 음성 채널에 들어가요.
2. 진행자가 텍스트 채널에 `/join`을 입력하면 녹음이 시작돼요.
3. 스터디가 끝나면 `/stop`으로 녹음을 멈춰요.
4. Craig가 보내준 링크에서 녹음 파일을 받아요.

> ⚠️ 녹음 파일은 **7일 뒤에 사라져요.** 스터디 끝나고 바로 받아두세요.

### 정리하기

1. **전사**: 녹음 파일을 클로바노트 같은 한국어 전사 앱에 올려 전사문을 만들어요.
2. **AI 정리**: 전사문을 AI에게 주고 아래 프롬프트로 회고 초안을 받아요.
3. **검토**: 진행자가 기술 용어나 틀린 내용을 고치고, **자기 생각 한 줄**을 덧붙여요.
4. **올리기**: `weekNN/회고.md`로 PR을 올려요.

### 녹음 관련 약속

- 녹음은 **모두가 동의한 경우에만** 해요. 녹음하기 싫은 날은 언제든 말해도 괜찮아요.
- **녹음 파일과 전사문은 레포에 올리지 않아요.** 정리한 회고만 올려요.
- 회고를 올린 뒤에는 녹음 파일과 전사문을 지워요.

## 🤝 우리의 규칙

- 메모는 **세 줄만 있어도 충분**해요. 잘 쓰려고 애쓰지 않기!
- 어려운 용어로 설명하면 바로 **"그게 뭔데?"** 물어보기
- 틀린 내용도 그대로 올리고, 나중에 알게 되면 고치기
- 바빠서 못 한 주는 부담 없이 넘어가기
- 규칙은 대화를 돕기 위한 것, 대화를 막으려는 게 아니에요

## 💡 키워드 풀

공부하다가, 글을 읽다가, 일하다가 모르는 단어가 생기면 **이슈로 등록**해 주세요.
키워드를 고를 때 여기서 하나 가져가고, 가져간 이슈에는 본인을 담당자로 지정해요.

| 라벨 | 의미 |
| --- | --- |
| `키워드` | 공부할 키워드 후보 |
| `남은질문` | 스터디에서 답하지 못한 질문 |
| `심화` | 다음 주에 더 깊게 이어갈 주제 |

> 예시 키워드: 커넥션 풀, 트랜잭션 격리 수준, 캐시 무효화, 멱등성, 로드밸런서, 메시지 큐
